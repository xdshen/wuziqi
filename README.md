# 五子棋 · 人机大战 (Gomoku)

一个基于 HTML5 Canvas + JavaScript 的五子棋人机对战游戏，内置高智商 AI，直接在浏览器中打开即可游玩。

## 功能特性

- **人机对战**：玩家执黑先手，挑战电脑 AI
- **高智商 AI**：采用 Alpha-Beta 剪枝 + 启发式评估 + 多层深度搜索
  - 识别棋型：连五、活四、冲四、跳冲四、活三、跳活三、眠三、活二等
  - 自动算杀：优先处理必胜/必堵局面
- **四级难度**：初级 / 中级 / 高级 / 大师（搜索深度 3~6 层）
- **悔棋功能**：支持回退一步（玩家 + AI 各一步）
- **交换执子**：可随时切换黑白方，体验后手防守
- **精美界面**：木质棋盘、棋子阴影、落子预览、最后一步红点标记

## 如何开始

无需安装任何环境，直接双击打开 `gomoku.html` 文件即可在浏览器中游玩。

```bash
# 或者启动一个本地服务器
python -m http.server 8080
# 然后访问 http://localhost:8080/gomoku.html
```

## AI 算法简介

1. **杀棋优先**：每回合先检查己方/对方是否存在连五、活四等 immediate win
2. **候选生成**：只评估与已有棋子距离 ≤2 的空位，大幅缩减搜索空间
3. **启发排序**：按棋型评分排序，仅取前 16~18 个候选点进行深度搜索
4. **Minimax + Alpha-Beta**：在限定深度内推演双方最佳走法
5. **模式匹配评估**：基于 9 格线段字符串匹配常见五子棋棋型，精确计分
